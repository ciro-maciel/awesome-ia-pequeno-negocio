## Étiquettes

Chaque entrée indique ce qu'elle est. Les étiquettes à côté aident à choisir : officiel quand elle vient de l'organisme qui définit la norme, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la manière de l'intégrer. Les entrées avec l'étiquette « de l'auteur » sont réalisées par Ciro Cesar Maciel et suivent les mêmes règles que toutes les autres.
