## MEIとSimples Nacional

義務について、政府の情報をそのまま。

- [Comitê Gestor do IBS](https://go.mymarketing.click/iapn-comite-gestor-do-ibs) - IBS（税制改革のもの）を管理する機関。 `公式` `無料`
- [Contribuição mensal do MEI](https://go.mymarketing.click/iapn-contribuicao-mensal-do-mei) - 毎月のDASの発行と支払い方法。 `公式` `無料`
- [Declaração anual do MEI](https://go.mymarketing.click/iapn-declaracao-anual-do-mei) - DASN-SIMEI（年間売上の申告）の提出方法。 `公式` `無料`
- [Lei Complementar 123/2006](https://go.mymarketing.click/iapn-lei-complementar-123-2006) - 零細企業憲章とSimples Nacional。 `公式` `無料`
- [Lei Complementar 214/2025](https://go.mymarketing.click/iapn-lei-complementar-214-2025) - 消費に関する税制改革の法律：IBS、CBS、選択的課税。 `公式` `無料`
- [MEI: perguntas frequentes](https://go.mymarketing.click/iapn-mei-perguntas-frequentes) - 個人零細事業者（MEI）に関する公式の回答。 `公式` `無料`
- [Nota fiscal do MEI](https://go.mymarketing.click/iapn-nota-fiscal-do-mei) - MEIが請求書（nota fiscal）を発行するタイミングと方法。 `公式` `無料`
- [Portal do Empreendedor](https://go.mymarketing.click/iapn-portal-do-empreendedor) - MEIの公式ポータル。開業、ガイド、サービス。 `公式` `無料`
- [Portal do Simples Nacional](https://go.mymarketing.click/iapn-portal-do-simples-nacional) - Simples NacionalとMEIのための連邦税務局ポータル。 `公式` `無料`
- [Relatório mensal de receitas](https://go.mymarketing.click/iapn-relatorio-mensal-de-receitas) - MEIの月次総売上報告書のひな形。 `公式` `無料`
